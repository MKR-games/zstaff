# 직원 스케줄러 v16 — 모바일 전용 UX 포함

GitHub Pages + Firebase Cloud Firestore 기반입니다.

## 모바일 정책

스마트폰에서는 근무 스케줄을 **조회 전용**으로 사용합니다.

모바일에서 불가능:
- 근무 스케줄 신규 등록
- 근무 블록 이동
- 근무 블록 리사이즈
- 근무 스케줄 삭제/수정
- 직원 순서 변경
- 직원 등록/삭제

모바일에서 특화:
- 주간 한눈에 보기
- 날짜별 상세 보기
- 개인 일정 추가
- 개인 일정 수정/삭제
- 관리자 ★ 구분
- 주말 퇴근 미정 표시
- Firebase 실시간 동기화 확인

## 모바일 주간 한눈에

직원별로 월~일 7일을 작은 표로 보여줍니다.
근무시간, 주말 출근, 개인 일정 여부를 빠르게 확인할 수 있습니다.

## 모바일 날짜별

하루를 선택하면 직원별 근무 여부와 개인 일정을 큰 카드 형태로 보여줍니다.
개인 일정이 있으면 `일정 수정` 버튼으로 바로 편집할 수 있습니다.

## 데스크톱

기존 v15의 모든 스케줄 편집 기능을 그대로 유지합니다.

## Firebase 무료 최적화

- 직원 목록 1문서
- 1주 = Firestore 1문서
- 현재 보는 주만 실시간 구독
- 최근 8주 자동 보관
- 약 900ms 저장 debounce
- App Check 선택 적용
- Node.js / npm / Firebase Hosting 불필요
