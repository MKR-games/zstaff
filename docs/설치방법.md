# 직원 스케줄러 앱 설치 방법

설치 주소: <https://mkr-games.github.io/zescape/>

## iPhone·iPad

1. Safari에서 설치 주소를 엽니다.
2. 화면 아래의 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택합니다.
4. 오른쪽 위의 `추가`를 누릅니다.

홈 화면에 생긴 `직원 스케줄러` 아이콘을 누르면 주소창 없는 앱 화면으로 실행됩니다. Mac, Xcode, Apple Developer 계정은 필요하지 않습니다.

## Android

1. Chrome에서 설치 주소를 엽니다.
2. 화면의 `앱 설치` 버튼을 누릅니다.
3. 설치 확인창에서 `설치`를 선택합니다.

설치 버튼이 보이지 않으면 Chrome 오른쪽 위 `⋮` 메뉴에서 `앱 설치` 또는 `홈 화면에 추가`를 누릅니다.

## 업데이트

GitHub Pages의 파일이 변경되면 앱을 다시 설치할 필요가 없습니다. 앱을 완전히 닫았다가 다시 열면 새 서비스 워커와 화면 파일이 적용됩니다.

## 삭제

- iPhone: 홈 화면 아이콘을 길게 누르고 `북마크 삭제` 또는 `앱 삭제`를 선택합니다.
- Android: 일반 앱과 동일하게 아이콘을 길게 누르고 `제거`를 선택합니다.
